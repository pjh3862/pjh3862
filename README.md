### 🛠️ 초보자의 첫 번째 진지한 프로젝트

**[Production Management Automation](https://github.com/pjh3862/production-management-automation)**

제조 현장의 공정별 재고, 생산 실적, 출하 계획을 연결해 **출하 대비 진도율을 한눈에 볼 수 있는 도구**를 만드는 중입니다.

```text
[기초재고] ──┐
[작업실적] ──┼──> [DB] ──> [재고 계산] ──> [진도율 대시보드]
[출하계획] ──┘
```

- **공정:** 가접 → 로보트 → 사상 → 가공 → 검사
- **꿈:** 현장에 내려가 하나씩 세지 않아도 재고를 확인하기
- **현실:** 버튼 하나 만들고 작동하면 잠시 감동하기
- **중요 원칙:** AI가 작성한 코드라도 계산 결과는 직접 검증하기

> 목표는 거창한 앱 개발자가 아니라, **현장에서 진짜 쓰는 작은 도구 하나를 제대로 만드는 것**입니다.

### 🎒 제 가방에 들어 있는 도구들

| 도구 | 현재 관계 |
| :-- | :-- |
| **Excel · Power Query** | 오래 알고 지낸 실무 동료 |
| **Power BI · Power Automate** | 반복 업무를 줄이기 위한 지원군 |
| **PostgreSQL · SQL** | 이제 막 대화를 시작한 사이 |
| **Node.js · 웹 개발** | 만나면 아직 조금 긴장되는 사이 |
| **GitHub · VS Code** | 메뉴부터 배우는 중 |
| **ChatGPT · Codex** | 설명을 여러 번 부탁하는 AI 학습 파트너 |

**주의:** 이 표는 기술 스택 자랑이 아니라 **학습 현황 보고서**에 가깝습니다.
