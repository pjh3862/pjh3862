### 🛠️ 요즘 만드는 것

**Production Management Automation**  
생산 현장에 필요한 재고·실적·출하·진도율 관리 시스템을 직접 구현하는 프로젝트입니다.

```text
[현장 작업 실적] ─┐
[공정별 기초재고] ─┼─> [데이터베이스] ─> [재고 계산] ─> [대시보드]
[출하 계획] ──────┘                         └─> [출하 대비 진도율]
```

- **공정 흐름:** 가접 → 로보트 → 사상 → 가공 → 검사
- **핵심 목표:** 현장에 내려가서 하나씩 세지 않아도 재고를 파악할 수 있도록
- **개발 방향:** 현장에는 간편한 입력, 사무실에는 믿을 수 있는 숫자
- **최종 보스:** `어제 기준으로는 맞았는데요?` 라는 문장

### 🧰 현재의 도구 상자

| 영역 | 도구 | 제 사용법 |
| :-- | :-- | :-- |
| 데이터 정리 | Excel · Power Query | 복붙 노동 줄이기 |
| 데이터 시각화 | Power BI | 숫자가 말하도록 만들기 |
| 업무 자동화 | Power Automate · Power Apps | 사람이 클릭할 일을 시스템에 맡기기 |
| 데이터 관리 | PostgreSQL · SQL | 파일이 아니라 데이터로 관리하기 |
| 개발·협업 | GitHub · VS Code · Node.js | 아이디어를 실제 도구로 만들기 |
| AI 활용 | ChatGPT · Codex | 질문을 설계하고, 만들고, 검증하기 |

<sub>※ 전부 전문가라는 뜻은 아닙니다. 실무에 써먹으면서 하나씩 레벨업 중입니다.</sub>
