### 🙋‍♂️ 간단한 소개

현장에서 생산계획, 공정, 재고, 납기와 관련된 일을 하고 있습니다.

일하다 보면 같은 내용을 여러 번 입력하거나, 숫자를 일일이 확인해야 할 때가 있습니다. 그럴 때마다 **“조금 더 편하게 할 방법이 없을까?”** 생각하곤 합니다.

그 호기심으로 AI와 자동화 도구를 찾아보다가 SQL과 웹 개발까지 공부하게 됐습니다.

개발은 아직 초보입니다. 모르는 게 훨씬 많고, 오류가 나면 검색부터 합니다. 그래도 어제 안 되던 게 오늘 되면 꽤 기쁩니다.

### 🛠️ 요즘 배우는 것들

| 분야 | 저와의 거리 |
| :-- | :-- |
| Excel · Power Query | 업무에서 자주 사용하는 도구 |
| Power BI · Power Automate | 조금씩 활용 범위를 넓히는 중 |
| PostgreSQL · SQL | 기초부터 배우는 중 |
| Node.js · 웹 개발 | AI 도움을 받아 하나씩 만들어 보는 중 |
| Git · GitHub | 아직 버튼 하나도 조심스럽게 누르는 중 |
| ChatGPT · Codex | 질문하면서 배우는 든든한 도구 |

> 사용해 본 도구와 잘 다루는 도구는 다릅니다. 위 목록은 **전문 분야보다 학습 기록**에 가깝습니다.

### 🌱 만들고 있는 작은 프로젝트

**[Production Management Automation](https://github.com/pjh3862/production-management-automation)**

생산실적, 공정별 재고, 출하계획을 연결해서 현황을 좀 더 편하게 확인할 수 있는 프로그램을 만들어 보고 있습니다.

`기초재고 → 생산실적 → 재고 계산 → 출하 대비 진도율`

아직 배우면서 만드는 단계라 부족한 부분이 많습니다. 특히 재고 계산처럼 중요한 부분은 **직접 확인하고 검증하는 것**을 우선으로 생각합니다.

목표는 거창하지 않습니다. **제가 하는 일에서 불편한 점 하나라도 줄이는 것**입니다.
